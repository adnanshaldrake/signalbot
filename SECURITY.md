# Security Policy

## Reporting Security Issues

We take the security of `signalbot` seriously. If you discover a vulnerability or security risk (particularly involving exchange credentials, secret exposure, or order handling), please do **NOT** open a public issue.

Instead, please report the vulnerability privately by emailing:
`adnanshaldrake@users.noreply.github.com` or via GitHub Private Vulnerability Reporting on this repository.

Please include:
- A description of the issue and potential impact
- Steps to reproduce or a proof of concept
- Any potential mitigation steps if known

We will acknowledge receipt of your report within 48 hours and work on a fix promptly.
